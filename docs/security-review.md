# 安全与公开发布检查

2026-10-22，综合结论 **CAUTION**。SkillSpector 静态扫描与独立源码审查共同用于判断，不以低分或“没有命中”代替安全结论。最终扫描数值见本次交付审查记录；原始版本为 100/CRITICAL，最高单项 HIGH。

## 本轮修复

- 旧 PDF 导出 HTTP 服务曾监听所有接口，并允许编码路径或目录链接越过服务目录。现在仅绑定 IPv4 loopback，校验 realpath 后的目录边界；越界、坏 URL 和缺失资源分别返回错误。真实 HTTP 回归覆盖正常请求、路径穿越、目录链接和错误恢复。
- 旧部署脚本会自动安装 CLI、尝试登录并默认生产发布，临时目录重命名有碰撞风险。现在要求显式 `--publish`，复用已安装且已登录的 CLI，默认预览，仅 `--prod` 选择生产；只在独立随机暂存目录中复制已审查静态文件，拒绝隐藏文件、链接与构建配置，并安全清理。回归使用本地模拟 CLI，没有访问 Vercel。
- 新增依赖锁文件；运行时与插件副本按同一维护源同步。公开示例只有通用教学内容，截图不包含个人账户、通知、机器路径或真实业务数据。

## 静态命中的上下文

原始扫描的 38 条结果已逐项人工核对。`Caveat` 是模板字体名，`print rules` 指 CSS 打印规则，`Npx Npx` 是 CSS 数值占位；这些命中不表示禁用安全提示、泄露系统指令或运行 npx。MIT 中的 “NOT LIMITED TO” 是许可证文字。实际 shell 删除与部署行为已按上节修复。

扫描器对部分长 JavaScript 表达式、设计文档和依赖分析存在跨度或时间限制，可能报告 partial；这些文件已额外做源码审查，不能把人工阅读写成静态扫描完整覆盖。未通过忽略规则或改字体名掩盖扫描分数。

## 真实使用边界

- `studio.js` 没有后台上传；页面文字与讲稿以纯文本保存到当前浏览器草稿，并在用户点击后导出文件。导出的 HTML **包含讲稿**，演讲者模式不是文件保密机制。
- `check-deck.cjs` 会执行指定 HTML 的 JavaScript。它阻止 HTTP(S) 资源请求，但不是针对恶意网页的安全沙箱。只处理可信、自作或经过审查的 HTML。
- `extract-pptx.py` 应输出到新目录，避免覆盖同名提取文件；未完成恶意压缩包资源耗尽模糊测试。
- 部署会将选择的静态内容发送至 Vercel，依赖安装会访问软件源；都不是阅读技能时自动发生的动作。文件目录与脚本参数依然由调用者负责审查。
- 依赖锁定不代表完整供应链审计。本轮没有执行真实云部署，也没有证明全部浏览器、Office 版本或未来输入安全。

私有开发历史在公开前已安排作者元数据清理，原始备份保留在私有本地目录；不把含私人信息的原始扫描日志发布到仓库。Git 引用清理不能保证服务端缓存永久删除。
