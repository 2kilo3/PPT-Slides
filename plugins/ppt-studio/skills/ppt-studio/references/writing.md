# 幻灯片与讲稿写作

先确定每页主张、证据和听众需要理解的关系，再分别写屏幕文字与口播。标题说明这一页实际讲什么，讲稿补足推理和上下文；页内不堆写作过程或空泛赞美。

依据 Humanizer-zh，调整重复、空话和机械句式时保持事实、数字、归因、否定、范围、时间和确定程度。正式汇报保留必要术语与语体，不强行口语化；不改代码、链接、版本号和数据。无需为了显得自然而添加故事或测量结果。

依据 anti-defensive-writing，用问题、方法、证据与价值组织讲述，删除无信息的自我辩护。对实际存在的局限、未完成事项和比较条件直接说明，不把“计划支持”写成“已支持”，也不隐去影响判断的不利结果。用户明确要求的内容与证据优先于叙事偏好。

完成后逐条比对原始材料，检查页面与讲稿是否一致。事实缺口放回资料核验，不用文风修改填补。两项指导已适配为本地规则，无需安装或执行外部技能；来源与 MIT 许可见 [来源记录](../docs/sources.md) 和 [第三方许可](../THIRD_PARTY_NOTICES.md)。
